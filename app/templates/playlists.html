Syncs run after every scan, and with Sync now. A synced playlist is copied to every other server that's on, and matched title by title: a film or episode that server doesn't have is left out and listed here. Edits to a copy are overwritten at the next sync; deleting the playlist deletes its copies. A playlist of the same name that sync didn't make is never touched. Franchisarr's own “… (Franchisarr)” playlists aren't listed: Make a playlist builds those on each server already. Uses the account Franchisarr uses on each server.
